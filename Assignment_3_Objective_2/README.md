# HIT140 Assignment 3 — Objective 2

This folder is a separate workspace for Objective 2 and does not replace the existing Objective 1 work.

## Required deliverables
- 104-row match-level dataset for Model 2.1 (goal difference)
- 208-row team-match dataset for Model 2.2 (goals scored)
- Exactly 8 pre-match explanatory variables per model
- No more than 4 explanatory variables shared by the models
- Python analysis, evaluation metrics, figures, and a report (maximum 4 A4 pages)

## Data integrity
Use only variables that would be known before kick-off. Do not use goals, shots, possession, cards, or other in-game statistics as predictors. Check dataset sources and all feature/row counts before writing findings.
